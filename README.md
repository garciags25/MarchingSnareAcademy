# Marching Snare Academy

## Project Status
🚧 This project is currently in development. New lessons, features, and improvements are still being added.

A JavaFX application designed to teach beginners the fundamentals of marching snare drum through structured lessons and practice features.

## Features
- Structured marching snare lessons
- Beginner-to-advanced lesson progression
- BPM-based metronome
- Audio click track
- Lesson completion tracking
- JavaFX GUI

## Technologies
- Java
- JavaFX
- Object-Oriented Programming
- Event-Driven Programming
